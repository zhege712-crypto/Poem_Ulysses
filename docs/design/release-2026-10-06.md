## 当前外观与布局

公共页面以纸色、墨色、短回纹和克制锈红组织内容；独立圆圈/斜条标题装饰已删除。标题下细线宽 56px，仅前 18px 使用锈红。正文、诗行、作者条目与稿件预览保持清楚的实色或透明阅读面；作者条目按分隔线排列，无卡片投影与悬停位移。

导航使用 78% 当前纸色混合、24px blur 与 130% saturation；底部主题栏使用胶囊形、24px blur 与 135% saturation，固定居中且距底 16px。轻量操作按钮、目录视图切换和搜索保留半透明控制层，视图切换与搜索分别为 20px / 12px blur。输入为 12px 圆角，稿件预览为 18px 圆角。这里记录 CSS 材质参数，不将其扩张为实体设备上的效果或性能承诺。

标题沿用 Cormorant Garamond / Noto Serif SC，界面沿用 Inter / Noto Sans SC，诗行保留楷体回退栈。公共标题字重 500：首页桌面/手机为 64px / 44px，内页为 48px / 34px，诗题为 40px / 30px；诗正文为 20px / 19px、2.15 倍行高。作品日期与系列为桌面 13px、手机 12px；主要操作为 14px。640px 以下导航分成品牌与导航两行，作者索引改为单列，列表元信息与表单操作可换行。公共页面主题为日间、夜间、护眼，通过 `html[data-theme]` 与 `--ui-*` 别名维持控制器颜色；字体不可用时使用各页回退栈。

漂流桌面为地图约占三分之二、右侧一处日志列表/阅读侧栏，地图和侧栏高度为 `clamp(430px, calc(100dvh - 310px), 650px)`；航迹顺序带在地图下方。820px 以下出现地图/日志切换，详情作为最高 70dvh、600px 的底部阅读层；这是可关闭的 region，不是带背景焦点隔离的模态框。手机主题栏位于页面顶部右侧，顺序带手写注记已取消旋转且关闭纵向溢出。

漂流默认高德区域地图，地球总览由明确按钮打开；缩放不自动切模式。“查看全部”适配地点而保留当前日志选择。日志正文和关联诗歌分别呈现，全文链接指向真实阅读页。列表、顺序带和上下站沿用日志数组顺序，`link:false` 保留航迹断点。旧扫描层、角框、斜纹、徽章、图例与滑杆被隐藏，旧 boot 样式不能代表当前可见功能。

## 运动、退出与存储

公共运动使用 `cubic-bezier(.16,1,.3,1)`：主题选中块滑动 340ms，目录视图选中块 320ms，正文切换 240ms，折叠分支 280ms。快速切换会取消上一轮正文 Web Animation；收起分支同步 `inert` 与 `aria-expanded`，主题/视图按钮同步 `aria-pressed`。普通色彩反馈约 180–200ms；可悬停设备的按钮轻移 2px、按下缩至 .97。内容默认可见；减少动态偏好关闭相关过渡、正文动画与位移。漂流减少动态规则将后代动画与过渡缩短至 `.01ms`。

开幕是约 3 秒的平面构成：锈红斜带、墨色圆、金色弧线、透明色面、短回纹与四字字形依次建立航迹，最后对齐真实首页标题。透明色面没有额外 backdrop blur。控制器读取首页字号、字重、字距、行高与位置；集成修复消除了旧开幕 400 与新首页 500 的字重差异。正常播放通过 `animationend` 结束，并有 3.1 秒计时兜底。

开幕默认隐藏，成功初始化后才锁滚动、暂时使背景元素 inert 并聚焦“跳过”。Tab 保留在跳过按钮；按钮、Escape、播放完成、实际视口变化或捕获的错误均释放遮罩，恢复原有 inert、滚动和焦点。`intro_poem_shown` 在播放前写入 sessionStorage，普通重复访问直接首页。减少动态、不支持原生 inert、存储读写失败均直接展示首页。`?intro=replay` 重播，附加 `intro-frame` 冻结 0–2900ms，`?preview=1` 冻结 2760ms；冻结仍可跳过，减少动态优先。

集成给七页既有主题控制器的 localStorage 读取与写入加了异常保护，并保护目录的 `catalog_view`、`catalog_collapsed` 读取、解析与保存。存储被禁用时主题和目录视图仍能切换，偏好可能无法跨访问记忆；开幕不会阻塞主页。

漂流配图灯箱已补充具名、至少 44px 的“关闭配图”按钮。缩略图支持 Enter/Space 打开，打开后聚焦关闭按钮；Tab 留在该按钮，Escape 优先只关闭配图并保留日志详情。按钮或背景点击也能关闭，关闭后焦点回原缩略图；关闭态同步 `inert` 与 `aria-hidden`。此修复针对漂流灯箱，不代表所有页面模态交互均已完成全面无障碍认证。

## 后续维护

- 修改公共 token、主题栏、字体或断点时，同步十份内联样式并检查最终层叠；先前样式仍可能以更具体选择器生效。保留具名主题操作、清楚的焦点和 44px 操作区。
- 修改首页标题时保留开幕的计算样式读取与提前准备内容机制；复核完整播放、跳过、重复访问、存储失败及减少动态下的退出状态。冻结预览仅供明确查询参数使用。
- 修改漂流时保持区域地图默认、地球主动切换、日志/诗歌分区及真实全文入口；地图失败时保留可读日志和重试路径。主题栏按漂流局部断点维护。
- 新增共址日志时检查地球针的选中显示：现实现只比较共址组首条 ID；当前五站坐标不同，验收未触发后续条目高亮限制。
- 维护数据排序按 [AGENTS.md](../../AGENTS.md) 约定；发布设计无需改动 Worker 权限、私稿或凭证。历史设计文档的刷新应另行安排，避免把公共视觉修改扩展到受保护工作台。
