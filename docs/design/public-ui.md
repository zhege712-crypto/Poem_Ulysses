# 公共界面：航迹手稿

2026-10-04。本文记录本次已实现的公共界面，视觉依据为用户确认的 `design-drafts/2026-10-04/proposal.md`。代码以各页 `<style id="public-ui-design">` 为准；本记录不替代 PRODUCT.md，也不扩展为账号工作台或漂流地图的设计规范。

## 范围与意图

覆盖 index、directory、read、authors、author、about、submit、status、privacy、partners 十个公共 HTML 页面。采用温润纸面、短回纹、稀疏几何与锈红强调，将阅读内容和可操作入口分别保持清楚。作者索引以分隔线组织条目，移除常驻火炬、星标及大面积装饰背景。首页旧 Intro 保留，本轮没有实现草案中的新开幕动画。作品数据、后端、登录与权限逻辑均不属于本轮修改范围。

## 色彩

三主题共享组件和操作，通过 `html[data-theme]` 切换；现有选择继续保存在 localStorage。新增 `--ui-*` 别名用于公共控制，避免主题按钮自己的 `data-theme` 属性意外重定义文字颜色。

锈红集中于必要入口、系列标题与少量标记。正文不放在图片纹理或透明卡片上。

## 字体与布局

既有字体继续使用：标题为 Cormorant Garamond / Noto Serif SC；普通文字为 Inter / Noto Sans SC；部分工具文字使用 system-ui；诗歌保留 Kaiti SC、STKaiti、KaiTi、Noto Serif SC 的楷体回退栈。Google Fonts 不可用时由本机回退字体承担排版。

首页标题采用 `clamp(46px,7vw,76px)`，页面标题采用 `clamp(36px,5vw,54px)`，诗题采用 `clamp(32px,5vw,48px)`。标题字重 500。诗正文为 20px、2.15 倍行高，允许过长内容折行；640px 及以下变为 19px。关于正文为 18px、1.95 倍行高，手机为 17px。元信息一般为 13–14px；目录树元信息使用实际复合选择器明确覆写为 13px。

页面保留既有各页内容宽度；导航容器最大宽度 1120px，左右 32px。640px 及以下导航分成品牌与导航两行，导航左右 20px，普通内容左右 22px。首页介绍左对齐，最近作品按分隔线排列；手机上作品标题与元信息上下排列。作者索引桌面两列、列间距 40px，手机一列。目录搜索与控制可换行，表单入口及操作在手机上下排列。

## 组件与状态

- 导航：可见文字链接；投稿入口锈红实心、4px 圆角。无 `.wrap` 的简化页眉补充计算式水平内边距。
- 主题工具栏：底部固定居中，z-index 150，距底 16px；容器 8px 圆角、1px 描边、5px 内边距、16px 模糊。三个具名主题按钮为 44px 高、至少 76px 宽，4px 圆角。选中以墨色底、纸色字和图标表达。移动规则曾设 10px 底距，但末尾统一覆写实际保持 16px，应以最终层叠值维护。
- 主按钮：墨色实心、纸色文字；其他操作保留轻量描边或文字形式。通用按钮至少 44px 高，5px 圆角。随机诗控制同时有图标和文字。
- 阅读：诗题、作者日期、诗正文和上一篇/下一篇保持原有顺序；短回纹不进入长正文。随机、返回和相邻作品导航为可见操作。
- 作者条目：透明背景，无阴影、无悬停位移，底部分隔线；姓名 28px，标签与别名使用普通文字，不堆叠胶囊。
- 表单：面板为较深纸色、5px 圆角；输入为页面纸色、4px 圆角、16px 字号。字段标签 15px，说明 13px、1.75 倍行高。保留现有提交、反馈与状态逻辑。
- 焦点：通用 `:focus-visible` 使用锈红 2px 外框与 5px 偏移；旧组件可能保留更具体的焦点偏移。

整体以色面和细线建立层级，公共作者条目不使用卡片阴影。浮层透明仅用于导航和主题工具栏。内容不再依赖滚动显现：`.reveal` / `.reveal-up` 明确保持可见。减少动态偏好关闭平滑滚动和相关过渡；首页旧 Intro 的降级机制继续由原逻辑负责。

## 维护与验证边界

站点无框架、无构建工具。公共 CSS 刻意在十个 HTML 文件中重复内联，以保留直接静态部署方式。修改共享 token、主题工具栏或断点时，应同步十份 `public-ui-design` 样式块，并注意旧样式的选择器优先级；不要只修一个页面。内容本身及现有 href、数据读取、表单与认证逻辑应继续按各页原实现维护。

实现截图保存在工作树外 `D:/poem_ulysses_web/design-drafts/2026-10-04/implementation/public-ui/`，包括 `desktop-home-light.png`、`mobile-read-light.png` 及各路由的桌面/手机、日间/夜间/护眼变体。partners 为立即跳转页，截图记录跳转行为，公共样式用于回退内容。布局检查与截图只证明被检查的本地状态；真实认证、私人状态链接及外部服务成功流程未因本轮视觉修改重新认证。浏览器验证不进行真实测试投稿。

新增页面应复用纸面、字体层级、具名主题控制和清楚的 44px 操作区；先让内容与动作易读，再添加短回纹。不要将本轮公共页面样式自动推广至外部 Worker 工作台或漂流地图。
