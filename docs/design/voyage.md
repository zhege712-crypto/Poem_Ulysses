# 漂流页：航迹手稿

## Overview

实现快照：2026-10-04；来源为本工作树的 `voyage.html`、`PRODUCT.md`、`DESIGN.md`。这是漂流页局部说明，不替换根设计系统或 sidecar。以「诗从这里经过。」引入真实地点和日志，地图承载位置，一处阅读侧栏承载文字，下面的顺序带承载航迹。纸墨、暖金细线、铁锈强调与半透明纸层形成安静的手稿气质。

根 `DESIGN.md` 的 Animus Extension 描述旧实现；本页实际默认高德地点地图，地球是显式选项。源码仍留有旧装饰、动画、滑杆和样式，不能把它们全部视为当前可见组件。本说明来自源码检查，视觉与浏览器验收由主任务执行。

## Typography

标题和日志正文使用 `Cormorant Garamond, Noto Serif SC, serif`；界面使用 `Inter, Noto Sans SC, sans-serif`；诗行和手写注记使用 `Kaiti SC, STKaiti, KaiTi, Noto Serif SC, serif`。顺序编号保留 JetBrains Mono。Oswald 仍在源码，旧徽章等组件隐藏。

- 页标题：`clamp(30px, 4vw, 52px)`；820px 以下为 32px。引言 15px，移动端 14px，最长 65ch。
- 阅读地点：32px；日志正文 17px / 1.9，保留原换行。
- 关联诗题：24px；诗行 17px / 2，保留原换行；作者与元信息 14px。
- 日志列表地点：20px；日期为无衬线 14px / 1.7。摘要沿用楷体 `.88rem / 1.75` 和两行截断；后置宽泛规则未覆盖更具体的既有选择器。
- 模式、关闭、阅读全文和站点按钮：14px；顺序带桌面 15px、移动端 14px。

## Layout

桌面页宽最多 1480px，两侧 40px；主区 `minmax(0, 2fr) minmax(300px, 1fr)`，间隔 24px。左边地图约占三分之二，右边只有一个侧栏：日志列表与阅读详情切换。地图与侧栏高度均为 `clamp(430px, calc(100dvh - 310px), 650px)`。侧栏列表滚动；阅读时固定头尾，中间正文滚动。顺序带位于地图下方，可横向滚动。

820px 及以下改为单列、两侧 16px，出现「地图 / 日志」视图按钮；各视图分别保存页面滚动位置。地图视图隐藏未阅读的日志侧栏，日志视图将地图和顺序带隐藏并折叠高度。地图高度为 `calc(100dvh - 330px)`，最小 340px。详情为固定底部阅读面板，高度 `min(70dvh, 600px)`，底部预留 70px。关闭返回列表状态；列表可继续作为面板后方内容。此面板是 region，未声明为模态对话框，也没有焦点循环或背景 inert。

主题栏沿用固定侧栏；700px 以下才成为底部横排，因此其断点与本页 820px 的视图断点不同。

## Elevation & Depth

深度主要来自薄边界与透明纸层：桌面侧栏 90% 纸色、22px blur；模式控制 92% 纸色、16px blur；地图标签 92% 纸色；移动阅读面板 97% 纸色、24px blur。移动侧栏本身关闭 blur。夜间和护眼主题另外注入既有半透明组件背景规则，最终背景取决于层叠。地图针移除旧辉光，选中使用轮廓圈。地球仍有按主题绘制的内阴影及大气光，图片灯箱保留暗背景和图片投影。

## Shapes

地图为直角矩形；桌面侧栏 12px 圆角；模式控制 8px，选中按钮 5px；移动详情顶部 16px 圆角。日志列表为无圆角、无投影的分隔行。地图针为 44×44px 透明按钮，内部 20px 圆点。侧栏标题只有一枚 24×24px 短回纹；顺序带末端仅一条「在这里，停一会儿。」楷体注记，旋转 −6°，移动端隐藏。

## Components

### 地点地图与地球

默认加载高德 2D 地图，初始中心 `[104.5, 35.5]`、zoom 7；加载后适配所有已定位地点。地点来自日志 WGS84 坐标，国内转换为 GCJ02。用户可拖动地图、滚轮缩放、使用 +/− 和「查看全部」。模式只由「地点地图 / 地球总览」按钮切换，缩放不自动切换模式。地图原生键盘、双击、滚轮选项关闭，滚轮由本页接管。

地球使用 D3 orthographic、真实陆地 TopoJSON、90° 裁切与大圆轨迹；支持拖动旋转、滚轮和按钮缩放。只绘制可见半球上的定位针。地球库及陆地数据提前请求，但仍以地点地图显示。切换主题会重新读取地球 CSS 色值并重绘。

### 航迹与共址记录

`logs.json` 的数组顺序决定日志列表、顺序带和上一站 / 下一站，不按日期重排。`link:false` 在当前记录之后断开连线，并阻止跨越该断点的站点按钮；无有效坐标也断开地图轨迹，但仍能通过列表或顺序带阅读。坐标要求有限数值、经度 ±180、纬度 ±90。

完全相同坐标共用一枚针；单条直接打开，多条切至日志视图并筛选该组，提供「查看所有日志」。选择记录恢复全部列表、同步顺序带 `aria-pressed`，地图定位或地球转向该站。地球共址针选中判断仍只比较组内首条记录 ID，选择后续记录时其选中外观可能不一致。

### 阅读侧栏

主体是日志自己的 `text`，空文字显示「此日志暂无文字」。地点、日期和可解析作者显示在顶部；无坐标明确标记「暂未定位」。关联诗歌为独立区块，只展示 `content` 前八个换行片段，阅读全文链接打开真正的 `read.html?id=…`，新标签页带 `noopener noreferrer`。没有关联诗歌时隐藏链接；关联 ID 缺失时显示暂不可用提示。关联诗歌配图懒加载、默认灰度，点击打开全彩灯箱。

打开详情向浏览器历史压入状态；关闭或返回键收起面板并将焦点恢复到相应日志按钮。Escape 关闭详情。仅在 700px 以下打开时主动聚焦地点标题，701–820px 的底部面板没有这一步。灯箱以点击关闭，现有 Escape 监听处理的是详情，灯箱本身没有独立 Escape 或焦点管理。

### 状态与恢复

- 初始日志提示加载中；地图 `role="status"` 提示「地图加载中…日志已可阅读」。无默认自动选中记录。
- 空日志提供「还没有漂流记录」与目录入口。
- 日志请求或格式失败显示重试读取、返回目录；诗歌和作者请求失败回退空数组，日志继续可读。
- 地图库 / 地图失败提示日志仍可阅读并提供「重试地图」。地图完成后清空状态；12 秒未完成显示失败提示。
- 地球失败将模式按钮改为「重试地球总览」；点击重试初始化。陆地优先本地，失败后 CDN。
- 日志与顺序选择按钮使用 `aria-pressed`；日志区域 `aria-live="polite"`；关闭详情使用 `inert` 与 `aria-hidden`。主要控制目标高度至少 44px；聚焦轮廓为 2px 加 3px 偏移，部分更具体既有规则仍使用 clay。
- `prefers-reduced-motion` 将本页后代动画和 transition 时长降至 `.01ms`；隐藏的扫描层不会显示。

## Do's and Don'ts

- Do 保持日志与关联诗歌分开，保留真实全文入口及数组顺序。
- Do 使用现有三主题语义颜色与局部铁锈强调，延续单侧栏、透明纸层、短回纹和单条手写注记。
- Don't 将旧源码中的扫描层、角框、斜纹带、徽章、图例、隐藏计数、滑杆或 boot CSS 作为当前可见功能；装饰层被显式隐藏，脚本未触发 boot。
- Don't 将本页记录推广成全站身份替换；根设计文档中的历史漂流描述不能代表这一局部实现。

实现仍依赖远程字体、高德、D3、TopoJSON 与可选陆地 CDN，不能保证离线地图。地图失败时可读日志与目录是恢复路径。浏览器实测、颜色对比及触屏可用性不由本文源码检查声称通过。
