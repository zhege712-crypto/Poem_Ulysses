# 漂流页：航迹手稿

## Overview

实现快照：2026-10-07；以本工作树当前 `voyage.html` 为实现真相，对照 `docs/design/public-ui.md` 与 `design-drafts/2026-10-06/art-implementation/brief.md`。这是漂流页局部说明，不替换根设计系统或 sidecar。以「诗从这里经过。」引入真实地点和日志，地图承载位置，一处阅读侧栏承载文字，下面的编号顺序带承载航迹。本轮静态美术同步公共暖纸、墨黑、锈红与圆润玻璃控件，保留真实数据和功能，不新增视差、收藏、记位或航迹动画。

根 `DESIGN.md` 的 Animus Extension 描述旧实现；本页实际默认高德地点地图，地球是显式选项。源码仍留有旧装饰、动画、滑杆和样式，不能把它们全部视为当前可见组件。本说明来自源码检查，视觉与浏览器验收由主任务执行。

## Typography

标题使用 `Cormorant Garamond, Noto Serif SC, serif`；界面使用 `Inter, Noto Sans SC, sans-serif`；日志正文、诗行和保留的手写注记使用 `Kaiti SC, STKaiti, KaiTi, Noto Serif SC, serif`。日志行编号保留 JetBrains Mono，站点圆标和阅读大编号使用衬线。Oswald 仍在源码，旧徽章等组件隐藏。

- 页标题：桌面 48px / 1.25、字重 500；820px 以下 34px。引言 15px，移动端 14px，最长 65ch。
- 阅读编号：54px / 1、字重 500；手机 40px。阅读地点：38px、手机 30px。
- 日志正文和关联诗行：20px / 2.15，手机 19px，保留原换行；关联诗题 28px、字重 500；作者与元信息 14px。
- 侧栏标题 26px；日志列表地点 23px、字重 500；日期无衬线 14px / 1.7。摘要楷体 17px / 1.9，仍两行截断。
- 品牌 24px、字重 500；桌面导航 15px，640px 以下 14px。模式、关闭、阅读全文和站点按钮 14px；顺序带衬线 18px / 1.5，手机 17px；圆形编号 16px。

## Layout

桌面页宽最多 1480px，两侧 40px；主区 `minmax(0, 2fr) minmax(300px, 1fr)`，间隔 24px。左边地图约占三分之二，右边只有一个侧栏：日志列表与阅读详情切换。地图与侧栏高度均为 `clamp(430px, calc(100dvh - 450px), 600px)`。侧栏列表滚动；阅读时固定头尾，中间正文滚动。顺序带位于地图下方，可横向滚动。

820px 及以下改为单列、两侧 16px，出现「地图 / 日志」视图按钮；各视图分别保存页面滚动位置。地图视图隐藏未阅读的日志侧栏，日志视图将地图和顺序带隐藏并折叠高度。地图高度为 `calc(100dvh - 330px)`，最小 340px。详情为固定底部阅读面板，高度 `min(70dvh, 600px)`，内边距 `20px 20px 82px`，底部留白避开主题栏。手机页内容本身预留 90px 底部空间；桌面主内容后保留 24px 间距。关闭返回列表状态；列表可继续作为面板后方内容。此面板是 region，未声明为模态对话框，也没有焦点循环或背景 inert。

主题栏桌面放在主内容后的独立页尾区域，宽度随内容、水平居中；手机固定底部居中、距底 16px，z-index 1700，高于阅读面板的 1600。导航容器最大宽 1120px、桌面左右 32px；820px 以下 16px，640px 以下 20px，并让导航独占品牌下方一行。

## Elevation & Depth

深度主要来自薄边界与透明纸层：导航 78% 纸色、24px blur / 130% saturation；桌面侧栏 92% 纸色、22px blur；模式、缩放与主题栏统一 82% 纸色、24px blur / 135% saturation。地图标签 92% 纸色；移动阅读面板保留既有透明背景与 24px blur，侧栏本身关闭 blur。夜间和护眼仍注入旧详情背景规则，因此该详情背景不能视为全部统一的新公共纸色。地图针没有旧辉光，选中使用轮廓圈。地球仍有按主题绘制的内阴影及大气光，图片灯箱保留暗背景和图片投影。

## Shapes

地图为直角矩形；桌面侧栏 12px 圆角；模式、缩放、主题、关闭及站点导航使用胶囊圆角；移动详情顶部 16px 圆角。日志为分隔行，内边距 22px 0。地图针为 44×44px 透明按钮、内部 28px 锈红圆点和可见编号；共址针显示记录数量。顺序带每站包含 30×30px 圆形编号与地点文字。页标题后加入 72×14px 金色短回纹，手机 48×10px；侧栏保留 24×24px 短回纹。既有「在这里，停一会儿。」注记保留但已取消旋转、改用淡墨，并在手机隐藏；本轮没有新增摘录或手写动画。

## Components

### 地点地图与地球

默认加载高德 2D 地图，初始中心 `[104.5, 35.5]`、zoom 7；加载后适配所有已定位地点。地点来自日志 WGS84 坐标，国内转换为 GCJ02。用户可拖动地图、滚轮缩放、使用 +/− 和「查看全部」。模式只由「地点地图 / 地球总览」按钮切换，缩放不自动切换模式。地图原生键盘、双击、滚轮选项关闭，滚轮由本页接管。

地球使用 D3 orthographic、真实陆地 TopoJSON、90° 裁切与大圆轨迹；支持拖动旋转、滚轮和按钮缩放。只绘制可见半球上的定位针。地球库及陆地数据提前请求，但仍以地点地图显示。切换主题会重新读取地球 CSS 色值并重绘。

### 航迹与共址记录

`logs.json` 的数组顺序决定日志列表、顺序带和上一站 / 下一站，不按日期重排。`link:false` 在当前记录之后断开连线，并阻止跨越该断点的站点按钮；无有效坐标也断开地图轨迹，但仍能通过列表或顺序带阅读。坐标要求有限数值、经度 ±180、纬度 ±90。

完全相同坐标共用一枚针；单条直接打开，多条切至日志视图并筛选该组，提供「查看所有日志」。选择记录恢复全部列表、同步顺序带 `aria-pressed`，地图定位或地球转向该站。地球共址针选中判断仍只比较组内首条记录 ID，选择后续记录时其选中外观可能不一致。

### 阅读侧栏

主体是日志自己的 `text`，空文字显示「此日志暂无文字」。地点、日期和可解析作者显示在顶部；无坐标明确标记「暂未定位」。关联诗歌为独立区块，只展示 `content` 前八个换行片段，阅读全文链接打开真正的 `read.html?id=…`，新标签页带 `noopener noreferrer`。没有关联诗歌时隐藏链接；关联 ID 缺失时显示暂不可用提示。关联诗歌配图懒加载、默认灰度，点击打开全彩灯箱。

打开详情向浏览器历史压入状态；关闭或返回键收起面板并将焦点恢复到相应日志按钮。Escape 关闭详情。仅在 700px 以下打开时主动聚焦地点标题，701–820px 的底部面板没有这一步。灯箱支持具名的 44px 关闭按钮、Enter/Space 打开缩略图、Escape 优先关闭配图并保留详情；打开时管理焦点与 Tab 循环，关闭后恢复来源焦点，以 inert 和 aria-hidden 隐藏收起的对话框。

### 状态与恢复

- 初始日志提示加载中；地图 `role="status"` 提示「地图加载中…日志已可阅读」。无默认自动选中记录。
- 空日志提供「还没有漂流记录」与目录入口。
- 日志请求或格式失败显示重试读取、返回目录；诗歌和作者请求失败回退空数组，日志继续可读。
- 地图库 / 地图失败提示日志仍可阅读并提供「重试地图」。地图完成后清空状态；12 秒未完成显示失败提示。
- 地球失败将模式按钮改为「重试地球总览」；点击重试初始化。陆地优先本地，失败后 CDN。
- 日志与顺序选择按钮使用 `aria-pressed`；日志区域 `aria-live="polite"`；关闭详情使用 `inert` 与 `aria-hidden`。主要控制目标高度至少 44px；聚焦轮廓为 2px 加 3px 偏移，部分更具体既有规则仍使用 clay。
- `prefers-reduced-motion` 将本页后代动画和 transition 时长降至 `.01ms`；隐藏的扫描层不会显示。

## Do's and Don'ts

- Do 保持日志与关联诗歌分开，保留真实全文入口及数组顺序。
- Do 使用现有三主题语义颜色与局部铁锈强调，延续单侧栏、透明纸层、短回纹和单条手写注记。
- Don't 将旧源码中的扫描层、角框、斜纹带、徽章、图例、隐藏计数、滑杆或 boot CSS 作为当前可见功能；装饰层被显式隐藏，脚本未触发 boot。
- Don't 将本页记录推广成全站身份替换；根设计文档中的历史漂流描述不能代表这一局部实现。

实现仍依赖远程字体、高德、D3、TopoJSON 与可选陆地 CDN，不能保证离线地图。地图失败时可读日志与目录是恢复路径。浏览器实测、颜色对比及触屏可用性不由本文源码检查声称通过。
