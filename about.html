关于 · 诗歌漂流

诗歌漂流 是一个收集诗意的角落。它像一片开放的海域，每一首诗都是一个漂流瓶，从不同的海岸出发，抵达这里。

这里没有固定的栏目，没有流量的焦虑，只有文字本身的重量。你可以在这里读诗，也可以投递你自己的诗——用 GitHub 发帖的方式，像把瓶子放进海里。

📜 缘起

这个网站源于一个简单的愿望：为那些安静的诗句，找一个不会被算法淹没的地方。在信息洪流中，诗歌是少数值得慢下来读的东西。

📮 如何投稿

点击顶部导航的“投稿”，会跳转到 GitHub Discussions。用你的 GitHub 账号登录后，新建一个帖子，把诗贴进去就好。
我会定期查看，审核通过后它会出现在目录里。配图可以直接拖入帖子，我会同步搬运。
